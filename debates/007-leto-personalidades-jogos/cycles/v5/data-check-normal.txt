2. Findings that matter for missing-data requests

The supplied code already shows important distinctions.

First, the working-tree Claudio implementation and the frozen release-Python implementation differ substantially. The ZIP's release test source explicitly refers to models/g4t2-leto-v3.pt. Establishing which source and runtime settings define the actual trained G4 Leto baseline is therefore valuable; treating an adjacent Claudio or CognitiveAgent configuration as G4 Leto's configuration could invalidate the theoretical comparison.

Second, the engine contains configurable neural, search, tactical, memory, opening and stochastic behavior. The saved checkpoint configuration and actual runtime overrides matter because source defaults need not equal the trained model's decisions.

Third, the supplied 440 historical timing entries are per-player thinking durations, not complete-game wall times. They include historical opponents and game records with different termination conditions. They must not be converted directly into observed complete games per second.
