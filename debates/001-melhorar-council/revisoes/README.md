# Revisões

A revisão ainda não começou. Este ficheiro é uma instrução e não conta como uma contribuição.

Primeiro fecha e regista o conjunto de propostas em [PARTICIPANTES.md](../PARTICIPANTES.md). Todos os revisores devem receber o mesmo contexto e todas as propostas desse conjunto.

Usa [o prompt de revisão](../../../prompts/02-REVER.md) e guarda as respostas em `<participante>.md`, com os mesmos identificadores da fase inicial. Inclui o conjunto de ficheiros e a versão efetivamente recebidos.

Se um novo revisor não tiver feito proposta inicial, identifica essa situação. Não lhe atribuas uma posição anterior inventada.
